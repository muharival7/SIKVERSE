# Catatan penyesuaian Admin ke referensi Figma

- Sidebar Admin diringkas menjadi Dashboard, Mahasiswa, Dosen, dan Rekap Absen; accordion Menu lainnya Admin disembunyikan untuk mengurangi item navigasi berulang.
- Admin welcome title dan subtitle disesuaikan dengan screenshot referensi.
- Panel Pengelolaan Sertifikat ditambahkan sebagai tautan kontekstual `Lihat` menuju route sertifikat.
- Route/halaman fitur admin yang lain tidak dihapus dari backend; mereka tidak dihapus permanen agar data dan fungsi terkait tidak rusak.
- Dashboard yang tersedia saat ini masih menggunakan grafik dan rekap kehadiran terbaru dari controller. Layout tidak mengganti data dengan angka contoh.
- Ini adalah penyesuaian awal berdasarkan view yang ada. Pemeriksaan/pengujian Laravel lengkap belum dilakukan.
